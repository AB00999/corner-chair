## ⭐ Featured Projects

### 1. 🏦 Family Bank Project
**Type**: Full Stack Web Application + Python CLI  
**Status**: ✅ Production Ready (v1.0.0)  
**Repository**: [AB00999/Family-bank-project](https://github.com/AB00999/Family-bank-project)  
**Live Demo**: http://127.0.0.1:5000 (Local)

#### What It Is
A comprehensive learning project demonstrating enterprise-level web development with security best practices. Includes a Flask web app, Python ATM simulator, and admin dashboard.

#### Key Features
- ✅ **User Authentication**: Secure registration & login with password hashing (PBKDF2)
- ✅ **Admin Panel**: Role-based access control (Admin/Technician/User)
- ✅ **Stock Simulator**: Virtual trading with simulated cash
- ✅ **ATM Simulator**: Python CLI with balance persistence
- ✅ **Database**: SQLite with proper schema and relationships
- ✅ **Security**: CSRF protection, secure cookies, input validation
- ✅ **Testing**: 5 comprehensive unit tests (all passing)
- ✅ **CI/CD**: GitHub Actions configured for automated testing

#### Tech Stack
- Python 3.8+
- Flask
- SQLite
- HTML/CSS/JavaScript
- Git/GitHub

#### What I Learned
- Web framework design with Flask
- Secure password handling and hashing
- Session management and authentication
- Database design and SQL queries
- Test-driven development
- GitHub best practices and deployment

## 🚀 How to Use These Projects

### Clone All Repos
```bash
# Family Bank
git clone https://github.com/AB00999/Family-bank-project.git

# Portfolio
git clone https://github.com/AB00999/Abdoul-portfolio.git

# Family Bank Concept
git clone https://github.com/AB00999/family-bank-concept.git
```

### Run Family Bank
```bash
cd Family-bank-project
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python app.py
# Open http://127.0.0.1:5000
```

### Run Barber Booking
```bash
cd Abdoul-portfolio/barber-booking-demo
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
python -m unittest discover -s tests -v
python app.py

```
